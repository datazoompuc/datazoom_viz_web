# datazoom_viz_web

Static, serverless rebuilds of Data Zoom Amazônia's data visualizations. Each subfolder is a self-contained app — plain HTML/CSS/JS reading pre-exported JSON, no server or build step required — published via GitHub Pages.

Source code, R export scripts, and the original Shiny apps live in [datazoom_viz](https://github.com/datazoompuc/datazoom_viz) (private); this repo holds only the built, static output that gets published.

## Apps

- [`ts_comex_exp_municipio/`](ts_comex_exp_municipio/) — COMEX exports by municipality: ranking, composition, year-over-year change, trends, municipality comparison, per-municipality composition, and product ranking views.
